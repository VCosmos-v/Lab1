Необходимо реализовать метод таким образом, чтобы он возвращал новый 
массив, в котором записаны все элементы массива arr кроме отрицательных. 
 
Пример: 
arr=[1,2,-3,4,-2,2,-5] 
результат: [1,2,4,2]

### Алгоритм решения

В методе задать переменную x для подсчета положительных чисел в числе равную размеру изначального массива, в цикле от 0 до размера изначального массива уменьшать x на 1 если число в данной позиции в изначальном массиве - отрицательное, после цикла создать новый массив размером x и счетчик k = 0, в цикле i от 0 до размера изначального массива, если число в изначальном массиве не отрицательное, то записать в позицию k нового массива число из позиции i изначального массива и увеличить k на 1, после цикла вернуть новый массив
